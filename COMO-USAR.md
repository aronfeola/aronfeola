# Tu socio de negocios — cómo usarlo

Este repo es la memoria de Claude como socio de tu negocio de impresión 3D. Lo que está
acá escrito, Claude lo sabe; lo que no, se lo olvida.

```
CLAUDE.md                 ← quién es Claude para vos y cómo trabaja (lo lee solo)
perfil/como-trabajo.md    ← cómo trabajás vos
negocio/                  ← equipo, costos, ofertas, clientes, competencia, ventas
plan/plan-de-negocio.md   ← estrategia y la cuenta de los US$1.200
objetivos/tablero.md      ← meta del mes, objetivos por semana, registro diario
investigaciones/          ← todo lo que Claude investiga
automatizaciones/         ← cotizador y lista de automatizaciones
agente-marketing/         ← agente de posteos estáticos para Meta Ads (método Charley T, 99 videos)
                            y el editor de posteos (herramientas/editor-posteos.html)
resultados/               ← resultados de anuncios
```

## Dónde hablar con él

- **Claude Code (recomendado):** abrí una sesión con este repo. Lee `CLAUDE.md` solo,
  y puede actualizar el tablero, las ventas y el plan por vos, y construir
  automatizaciones.
- **Proyecto en claude.ai:** pegá `CLAUDE.md` en las instrucciones y subí las carpetas
  como archivos. Sirve para charlar, pero no puede actualizar los archivos solo.

## Qué decirle

- "Vendí 3 llaveros a $X a Juan por Instagram" → lo anota en ventas y en el tablero.
- "Hoy contacté a 8 personas, 2 respondieron" → actualiza el avance.
- "Investigá cómo trabaja [persona] con [tema]".
- "Analizá este anuncio y guardalo como **estilo oro**" (adjuntá la imagen).
- "Hacé un anuncio tipo **oro** para el llavero con logo."
- "Armame la oferta corporativa con lo que tengo".
- "Construí la automatización n.º 3".
- "Revisemos la semana".

## Recordatorios

Cada día hábil a las 7:47 (hora de Argentina) te llega un mensaje con los objetivos del
día y el avance de la meta. Lunes: la semana. Viernes: la revisión.
